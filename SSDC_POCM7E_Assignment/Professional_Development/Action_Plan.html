Professional Development Action Plan

Module: Secure Software Development (SSDC_PCOM7E)

This action plan outlines targeted professional development goals identified during the SSDC_PCOM7E module, focusing on continuous improvement in secure software development practices.

Development Area Action Timescale Expected Outcome
Advanced Security Architecture Further study of distributed systems security and architectural design 6–12 months Enhanced understanding of securing distributed systems, including trust boundaries, communication flows and monitoring challenges across multiple components.
Secure Code Practices Apply structured input validation and secure coding techniques across all new projects Ongoing Reduction in vulnerabilities related to input handling, including injection risks and logic flaws in validation mechanisms.
Vulnerability Assessment & Mitigation Develop deeper expertise in identifying and mitigating vulnerabilities using analysis tools and structured review 6 months Improved ability to identify weaknesses at both code and design level, including algorithmic vulnerabilities such as ReDoS and logic-based flaws.
Cryptography and Post-Quantum Security Develop expertise in ML-KEM and Kyber as post-quantum cryptographic mechanisms 6–12 months Stronger understanding of quantum-resistant encryption and its application in securing modern communication systems.
Security Testing Apply structured testing techniques such as boundary analysis and equivalence partitioning in practice 6 months Improved ability to detect edge-case vulnerabilities and reduce untested execution paths that may introduce security risks.
Academic and Professional Development Continue MSc studies in Cyber Security and Artificial Intelligence Ongoing Continued development of advanced theoretical and practical knowledge in secure software development and related domains.
Reflection & Continuous Learning Maintain structured reflection on security decisions and system design choices Ongoing Stronger linkage between experience, theory and practice, supporting continuous improvement in secure system design and decision-making.
