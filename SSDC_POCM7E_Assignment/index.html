Secure Software Development (Computer Science)

Module code: SSDC_PCOM7E

This page presents my individual e-portfolio submission for the Secure Software Development module. The portfolio evidences the development of secure coding practices, risk-aware architectural thinking, secure SDLC integration, and systematic testing strategies across Units 1–12.

The structure of this portfolio reflects the progression from foundational secure development principles (risk culture, SDLC models, UML modelling) towards language-level security analysis, testing methodologies, vulnerability classification and secure implementation practices.
